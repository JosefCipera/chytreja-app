## Co je hotovo

### Engine v1 pipeline (plně funkční)

```
fetchHealthData
  → activation.js       (CONFIRMED/PREDICTED stavy z diagnóz + onboarding)
  → inference.js        (odvozené stavy: GAIT_INSTABILITY, FALL_RISK UNKNOWN, PN)
  → computeProjections  (risk trajectory pro každý aktivní uzel)
  → buildInformationNeeds (missing evidence per uzel)
  → evaluateDecisionGate (OPEN/WATCH/CLOSED per uzel)
  → computeSystemLeverage (leverage_affinity × node score)
  → computeSystemConstraint (bottleneck = highest threat × coverage × confidence)
  → computeNextBestAction (Safety Gate → Device Fit → NBA ranking)
```

### Functional Mobility Slice v0.1 — PASS

**Supabase migrace (live):** `migrations/add_functional_mobility.sql`
- 5 nových sloupců v `longevity_actions`: `modality`, `support_sides`, `stability_support`, `upper_body_demand`, `load_distribution`
- 4 nové `ASSISTIVE_PROTOKOL` akce (`node_id='rovnovaha'`): `UNAIDED`, `ONE_CRUTCH`, `TWO_POLES`, `WALKER`

**Engine rozšíření:**
- `PERIPHERAL_NEUROPATHY` → inferuje `instability_type=PROPRIOCEPTIVE`, `laterality=UNKNOWN`
- `GAIT_INSTABILITY` → `PREDICTED_CURRENT` při PN + absence protektivních odpovědí
- `FALL_RISK UNKNOWN` → přidáno do inference když GAIT_INSTABILITY predicted + `recent_falls` nezodpovězeno
- Safety Gate Rule 7: `BALANCE_PROTOKOL`/`STABILITY_PROTOKOL` + `GAIT_INSTABILITY` → `SAFE_WITH_MODIFICATION`
- Device Fit: `laterality=UNKNOWN` → všechna zařízení `UNKNOWN` → `NEEDS_MORE_EVIDENCE`

### NBE (Next Best Evidence) — PASS

Comparator lexicografický (A urgency → B decision_impact → C uncertainty_reduction → D cost):
- `recent_falls` vítězí na B (`decision_impact=high`) díky `FALL_RISK UNKNOWN` v node_states
- Správné pořadí: `recent_falls` | urgency=high | impact=high | cost=very_low

### Kovářová out-of-sample test — PASS

Test skript: `scripts/test-nba-kovarova.mjs`

Kovářová profil: žena, 76 let, PERIPHERAL_NEUROPATHY, pády v anamnéze (bez direct `recent_falls=yes`), atrial_fibrillation, antikoagulancia.

Klíčové výsledky:
- 7 aktivních node_states včetně `FALL_RISK UNKNOWN`
- NBE: `recent_falls` jako první (urgency=high, impact=high, cost=very_low) ✅
- UNAIDED: `NEEDS_MORE_EVIDENCE` (ne `SAFE`) ✅
- ONE_CRUTCH/TWO_POLES/WALKER: `DEVICE_FIT=UNKNOWN` (laterality neznámá) ✅
- BALANCE/STABILITY akce: `SAFE_WITH_MODIFICATION` (ne `SAFE`) ✅
- SYSTEM_CONSTRAINT: `PERIPHERAL_NEUROPATHY` jako bottleneck ✅

## Architekturní rozhodnutí (trvalá)

- `laterality=UNKNOWN` pro PN: PN inferuje mechanismus (proprioceptivní), ne strannost
- `FALL_RISK UNKNOWN` do inference (ne jen activation) když GAIT_INSTABILITY predicted + `recent_falls` nezodpovězeno
- Safety Gate Rule 7 je obecný (`protocol_type` check), ne per-action hardkód
- `longevity_actions.node_id` je FK na `longevity_nodes` (Vesmír uzly), ne Engine Master node ID
